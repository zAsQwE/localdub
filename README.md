# LocalDub

Лаунчер для **What The Dub?** на Windows и Linux: игра по локальной сети без интернета.
Друзья играют с телефонов через браузер, реплики озвучиваются на компьютере через Piper.

- Патч для игры ставится и убирается одной кнопкой, оригинал сохраняется.
- В лобби игры вместо `playwtd.com` показывается адрес LocalDub и QR-код для телефонов.
- Хост с телефона начинает игру, отменяет старт и пропускает вступление.
- Можно играть и вдвоём, и одному — тогда без голосования и очков.
- Свой код комнаты, в том числе по-русски.
- Всё в одном окне: игра, настройки и мастер первого запуска.

> Неофициальный проект. Не связан с авторами What The Dub? и не распространяет
> файлы игры — нужна своя копия из Steam.

## Скачать и запустить

В **Releases** скачайте файл для своей системы:

- **Windows 10/11 x64:** `LocalDub-windows-x64.exe` — откройте двойным щелчком.
- **Linux x64:** `LocalDub-linux-x64.run`:

  ```sh
  chmod +x LocalDub-linux-x64.run
  ./LocalDub-linux-x64.run
  ```

Python, Tkinter, .NET Runtime 8, Piper и русский голос уже внутри.
Исходники и отдельная установка зависимостей не нужны. После скачивания программа работает без интернета.
На Linux нужна обычная графическая система с X11/XWayland и glibc 2.28+.

## Установить патч и играть

При первом запуске откроется мастер: язык, папка игры, код комнаты и установка патча.
Любой шаг и весь мастер можно пропустить — всё это есть на вкладке **«Настройки»**.

1. Выберите папку установленной **What The Dub?** — внутри должна быть `WhatTheDub_Data`.
2. Нажмите **«Запустить игру»** и оставьте LocalDub открытым. Патч встанет сам, если его ещё нет.
3. Друзья в той же сети открывают адрес или QR-код и вводят имя и код комнаты с экрана игры.

Адрес для телефонов игра показывает сама: в лобби вместо `wtd.tdot.space` или
`playwtd.com` будет адрес LocalDub, а в правом нижнем углу — QR-код.

Начать партию, отменить старт во время отсчёта и пропустить вступление может только
хост — первый вошедший игрок или тот, кого назначила игра. На телефоне он отмечен звёздочкой.
Обычно для игры нужны трое, но можно начать и вдвоём или одному: игра пройдёт
без голосования и очков.

**«Убрать патч»** возвращает оригинал. Русский перевод TDoT сохраняется.
После обновления или проверки файлов игры в Steam установите патч повторно.
В Windows разрешите LocalDub доступ к частной сети в брандмауэре.

### Код комнаты

По умолчанию код придумывает игра. В настройках можно задать свой: 3–8 букв или цифр,
латиницей или по-русски (например, `КИНО`). Буква Ё считается за Е, а похожие буквы
не зависят от раскладки: `KOT` на телефоне подойдёт к коду `КОТ`.
Новый код появляется со следующей комнатой. Если шрифт игры не покажет кириллицу,
выберите код латиницей.

### Настройки

Код комнаты, язык, голос и модель Piper, адрес для друзей (для Radmin VPN и туннелей),
порт и путь к .NET. Отсюда же можно пройти мастер первого запуска заново.

## Для разработки

Нужны Python 3.10+ с Tkinter, .NET Runtime 8 и Piper с моделью либо eSpeak NG.
Запуск: `./run.sh` или `run.bat`. На Windows `install-windows.bat` установит недостающее.
Аргументы: `--game "/путь/к/игре"`, `--port 9000`, `--headless`, `--diag`.
Запасной веб-пульт доступен по `--browser`.

Проверки: `python3 tests/run_all.py`; окно лаунчера — `python3 tests/test_desktop.py` (нужен дисплей).

Мост внутри игры (`wtd/bridge/Bridge.cs`) собирается Mono против сборок игры:
`sh wtd/bridge/build.sh`, затем скопируйте `wtd/build/LocalDubBridge.dll` в `wtd/prebuilt/`.
При запуске игры LocalDub сам обновит мост в её папке.

| Папка | Что внутри |
|---|---|
| `ld/` | приложение: окно (`desktop.py`), сервер, реле телефонов, патч, озвучка |
| `web/` | страница для телефонов и запасной веб-пульт |
| `wtd/` | мост внутри игры и патчер сборки |
| `tests/` | проверки |
| `tools/`, `packaging/` | сборка готовых файлов |

Сборка готовых файлов (Python 3.12+, для `.exe` также [NSIS](https://nsis.sourceforge.io/Download)):

```sh
python3 tools/build-release.py --target all
```

Файлы появятся в `dist/`. Компоненты скачиваются с проверкой контрольных сумм;
повторная сборка использует кэш. Лицензии находятся внутри программы в `LICENSES/`.

### Выпуск релиза

Готовые программы весят 130–170 МБ и в репозиторий не кладутся (`dist/` в `.gitignore`).
Их собирает GitHub Actions: опубликуйте релиз, и workflow **Build apps** соберёт оба файла,
проверит их на Linux и Windows и приложит к релизу.

```sh
gh release create v1.0.0 --title "LocalDub 1.0" --generate-notes
```
